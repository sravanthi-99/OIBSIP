# Temperature Converter
## Project Overview
Temperature Converter is a simple and responsive web application that converts temperature values between Celsius, Fahrenheit, and Kelvin.
This project was developed as **Task 3 – Temperature Converter Website** for the **Web Development & Designing Internship at Oasis Infobyte (OIBSIP)**.
## Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Input validation
- Absolute zero temperature validation
- Displays all three temperature units
- Clean and responsive user interface
- Mobile-friendly design
## Technologies Used
- HTML5
- CSS3
- JavaScript
## Temperature Units
- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)
## Project Sections
- Temperature input
- Unit selection
- Convert button
- Result display
