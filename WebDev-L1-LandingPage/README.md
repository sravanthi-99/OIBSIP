# DEVARA – Travel Landing Page
## Project Overview
DEVARA is a responsive travel landing page designed to showcase popular travel destinations and travel packages in a simple and attractive way.
This project was developed as **Task 1 – Landing Page** for the **Web Development & Designing Internship at Oasis Infobyte (OIBSIP)**.
## Features
- Responsive travel landing page
- Sticky navigation bar
- Home section with call-to-action button
- Popular destinations section
- Travel packages section
- About section
- Contact section
- Smooth navigation
- Mobile-friendly design
## Technologies Used
- HTML5
- CSS3
